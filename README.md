# 🎓 Student Performance Prediction

## 📌 Project Overview
This project uses Machine Learning (Logistic Regression) to predict whether a student will pass or fail based on academic and demographic features.

---

## 📊 Dataset
- Gender
- Race/Ethnicity
- Parental Education
- Lunch
- Test Preparation
- Math Score
- Reading Score
- Writing Score
